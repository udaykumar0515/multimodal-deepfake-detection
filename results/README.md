# Deepfake Detection V2 Research Results

This directory contains the final research evidence generated by evaluating the Multi-Task (V2) Deepfake Detection architecture on the held-out test set. 

**This directory is the single source of truth for all reports, research papers, presentations, and viva documentation.**

## Directory Structure

*   **`metrics/`**
    Contains the numerical performance results (e.g., Accuracy, F1-Score, ROC-AUC) across the Image, Audio, and Fusion heads. Use `test_metrics.json` for top-level quantitative reporting.

*   **`predictions/`**
    Contains the raw held-out test predictions (`test_predictions.csv`). This allows for completely reproducible downstream analysis without re-running the model inference.

*   **`confusion_matrices/`**
    Contains the graphical confusion matrices for the Image, Audio, and Fusion heads. Essential for visualizing true vs. false predictions across the binary labels.

*   **`roc_curves/`**
    Contains ROC/AUC figures for all three prediction heads. Use these to report threshold-independent classification performance.

*   **`precision_recall_curves/`**
    Contains PR curves and Average Precision scores. **Crucial** for proper evaluation given the inherent class imbalance in the FakeAVCeleb dataset.

*   **`performance_curves/`**
    Contains the training and validation learning curves (`training_history.json`). Useful for demonstrating model convergence and the lack of overfitting.

*   **`modality_analysis/`**
    Contains the four-category modality analysis (`modality_category_results.csv`). **Crucial** for demonstrating that the V2 architecture successfully decoupled the visual and audio branches (e.g., proving the Audio Head detects FakeAudio even when paired with RealVideo).

*   **`error_analysis/`**
    Contains false positives (`false_positives.csv`) and false negatives (`false_negatives.csv`). Essential for the Discussion/Limitations sections of research papers to analyze *why* the model failed on certain samples.

*   **`gradcam/`**
    Contains the interpretability figures. Separated by the four modality categories. Demonstrates the regions/features that the Image and Audio heads attributed their predictions to. *(Note: Grad-CAM visualizes attribution, not definitive physical deepfake artifacts).*

*   **`dataset_summary.json`**
    Contains a high-level summary of the dataset and the evaluated subsets to quickly reference total sample counts.

## Recommended Evidence for Project Report

When compiling your final documentation, use the following mapping to locate your evidence:

*   **Dataset Section:** Refer to `dataset_summary.json`
*   **Methodology Section:** Architecture documentation + `gradcam/` examples
*   **Training Section:** `performance_curves/`
*   **Results Section:** `metrics/` + `confusion_matrices/` + `roc_curves/` + `precision_recall_curves/`
*   **Multimodal Analysis:** `modality_analysis/`
*   **Error Analysis / Limitations:** `error_analysis/`
*   **Interpretability:** `gradcam/`
